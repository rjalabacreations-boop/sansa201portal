# SANSA 201 Portal

A digital companion for school personnel records — a personal innovation developed by **Ralf Jayvene C. Alaba**, Administrative Officer, Sarangani National Sports Academy, Schools Division of Sarangani, Department of Education.

## What this is

SANSA 201 Portal helps School Administrative Officers organize, monitor, and maintain school personnel information — complementing, not replacing, the official 201 file. Features include:

- Centralized personnel profiles (personal, education, employment, compensation, government IDs)
- Automated Step Increment and Loyalty Award tracking, confirmed by the admin before anything changes
- Self-service submission for new hires and update requests
- Scanned 201 document uploads, admin-only access
- Bulk CSV import and inter-school Transfer Packets for personnel moving between schools
- Role-based access (Admin, Employee, Public) with auto-logout and print restrictions to protect unattended devices

## Important notes

- **This repository contains only the application code — no personnel data.** Each school's actual data lives in their own private Google Sheet, connected separately by each school's administrator. Nothing in this file can access or expose anyone's personal information.
- This is a **personal innovation**, developed independently using AI-assisted development tools for coding assistance, with all planning, design, and testing directed by the developer.
- Not an official DepEd system — a complementary tool piloted at Sarangani National Sports Academy (SANSA).

## Hosting this yourself

This is a single, self-contained HTML file. To host your own copy:

1. Enable GitHub Pages for this repository (Settings → Pages → deploy from this branch)
2. Set up your own Google Sheet and Apps Script backend — see the Installation Guide provided separately
3. Connect your instance in the app's own Settings page
